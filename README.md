# STM32 学习记录（STM32F103C8T6）

跟着江协科技（江科大）STM32 入门教程逐个实验写下来的代码与笔记，一个实验一个工程，每个工程里都有一份 README 说明功能、接线和踩过的坑。

## 硬件与开发环境

| 项目 | 说明 |
|---|---|
| 主控 | STM32F103C8T6 最小系统板（江科大套件） |
| 开发环境 | Keil MDK 5（ARM） |
| 代码库 | ST 标准外设库 SPL（不是 HAL 库） |
| 下载调试 | ST-Link |

## 单个工程的目录结构

每个实验文件夹内部结构一致，双击 `Project.uvprojx` 即可用 Keil 打开：

| 目录 / 文件 | 作用 |
|---|---|
| `Library/` | ST 标准外设库源码（stm32f10x_gpio.c 等） |
| `Start/` | 启动文件 startup_stm32f10x_md.s、core_cm3、system_stm32f10x、寄存器总头文件 stm32f10x.h |
| `System/` | `Delay.c/.h` 毫秒延时 |
| `User/` | `main.c`、中断服务函数 `stm32f10x_it.c`、外设开关 `stm32f10x_conf.h` |
| `Hardware/` | 外设驱动（OLED、按键、蜂鸣器等，部分实验有） |
| `Project.uvprojx` | Keil 工程文件 |
| `README.md` | 该实验的功能、接线、代码要点、踩坑记录 |

`Objects/`、`Listings/`、`DebugConfig/` 是 Keil 编译产生的中间文件，以及 `*.uvguix.*`（本机个性化界面配置），都已在 `.gitignore` 里排除，不会出现在仓库里。

## 编译与下载

1. 用 Keil MDK 打开某个实验目录下的 `Project.uvprojx`
2. `Project → Build Target`（或 F7）编译
3. 接上 ST-Link，`Flash → Download`（或 F8）下载到板子
