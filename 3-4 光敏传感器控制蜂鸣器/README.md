# 3-4 光敏传感器控制蜂鸣器

## 功能
光敏传感器检测环境光：光线暗（用手捂住光敏电阻）时蜂鸣器响，有光照时蜂鸣器停。

## 接线
- 光敏传感器 DO（数字输出）→ PB13
- 蜂鸣器 IO → PB12
- VCC → 3.3V
- GND → GND

## 用到的代码
- `System/Delay.c/.h`：延时（本实验主逻辑未直接用，工程模板保留）
- `Hardware/LightSensor.c/.h`：`LightSensor_Init`、`LightSensor_Get`；PB13 配**上拉输入 IPU**，读 DO 引脚电平
- `Hardware/Buzzer.c/.h`：`Buzzer_Init`、`Buzzer_ON/OFF/Turn`；PB12 推挽输出，低电平响
- `User/main.c`：初始化蜂鸣器和光敏，while 循环里 `if (LightSensor_Get() == 0)` 响，否则停

## 遇到的问题
- **模块输出极性和教程相反**：教程代码判断方向和自己板子对不上，现象反着来。先别硬拧电位器，先确认模块 DO 在"有光/遮光"两种极端条件下分别输出什么电平，再把 main 里的判断改成对应的 `== 0` 或 `== 1`。本工程实测遮光时 DO 为低，所以用 `== 0` 触发 `Buzzer_ON`。
- **阈值靠模块上的电位器调节**：旋转板载电位器改变 DO 翻转的光线临界点；调的时候一边看模块上的指示小 LED，一边看蜂鸣器动作。
- 先用极端条件定位方向：拿手机闪光灯直接照模块（最亮）和用手完全捂住（最暗），两种状态各看一次电平/现象，就能确定触发方向，避免在中间亮度来回试。
- 光敏模块给的是**数字量 DO**（高低电平），不是模拟量；想读连续光照强度才需要接 AO 走 ADC。
