# 3-3 蜂鸣器

## 功能
PB12 推挽输出控制有源蜂鸣器，按固定节拍响停：响 100ms、停 100ms，重复三轮，最后响 100ms、停 700ms，循环播放（"滴-滴-滴——"的节奏）。

## 接线
- 蜂鸣器 IO → PB12
- VCC → 3.3V
- GND → GND

## 用到的代码
- `System/Delay.c/.h`：`Delay_ms` 延时
- `User/main.c`：开 GPIOB 时钟 → PB12 配推挽输出 → while 循环里 `GPIO_ResetBits` 响、`GPIO_SetBits` 停，配合延时控制节拍
- 关键配置：蜂鸣器和 LED 一样是被动执行机构，用推挽输出 Out_PP 直接驱动

## 遇到的问题
- 这里用的是**有源蜂鸣器**（自带振荡电路，给高低电平就响/停），不需要给 PWM 方波；无源蜂鸣器才需要靠翻转电平或 PWM 出声音频率，两者别搞混。
- 套件蜂鸣器也是低电平导通响：`ResetBits`（拉低）响，`SetBits`（拉高）停。
- 响停节奏完全由两段 `Delay_ms` 控制，改延时数值就能改节拍长短。
- 蜂鸣器电流比 LED 大，若声音很小或不响，先检查共地和 3.3V 供电是否接好。
