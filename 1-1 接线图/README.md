# 1-1 接线图

## 功能
本文件夹不放代码，只放江科大 STM32 课程每个实验对应的接线图（jpg 图片），做实验前对照图片把杜邦线接好。

## 接线
- 图片命名规则：`章节号-小节号 实验名.jpg`，例如 `3-4 按键控制LED.jpg`、`5-2 旋转编码器计次.jpg`、`6-2 定时器外部时钟.jpg`。
- 接线时以图片上标注的单片机引脚（PA/PB/PC）、3.3V、GND 为准，不要凭记忆插线。
- 目前已用到的图：2-1 工程模板、3-1 LED闪烁、3-2 LED流水灯、3-3 蜂鸣器、3-4 按键控制LED、3-5 光敏传感器控制蜂鸣器、4-1 OLED显示屏、5-1 对射式红外传感器计次、5-2 旋转编码器计次、6-1 定时器定时中断、6-2 定时器外部时钟、6-3 PWM驱动LED呼吸灯。
- 其余图片（I2C/SPI/RTC/看门狗/FLASH/串口/低功耗等）是后面章节还没做到的实验，先存着备用。

## 用到的代码
- 无代码，纯参考图片。

## 遇到的问题
- 图片里的引脚号一定要和工程源码里配置的引脚对得上；接错脚时程序不会报错，但现象完全不对，先回头核对接线图和源码引脚。
- 杜邦线接触不良也是常见现象，出现电平乱跳、计数不准时先换线、重插。
